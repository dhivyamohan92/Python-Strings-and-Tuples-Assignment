# Python-Strings-and-Tuples-Assignment


## 📌 Project Overview

This project demonstrates basic Python programming concepts related to **Strings and Tuples**.

The assignment focuses on:

- String concatenation
- String indexing
- String slicing
- String reversal
- Built-in string methods
- Tuple creation
- Tuple concatenation
- Tuple repetition
- Tuple indexing
- Tuple slicing

The assignment is completed using **Python** in Google Colab or Jupyter Notebook.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand how strings can be concatenated.
- Perform indexing and slicing operations on strings.
- Reverse a string using slicing.
- Extract specific words from a string.
- Use Python string methods such as `upper()`, `lower()`, `capitalize()`, `count()`, and `replace()`.
- Create and combine tuples.
- Repeat tuple elements.
- Access individual tuple elements.
- Perform tuple slicing.

4. Tuple Operations

Two tuples are created:

t1 = (10, 20, 30)
t2 = (40, 50, 60)
Tuple Concatenation
t_combine = t1 + t2

Output:

(10, 20, 30, 40, 50, 60)
Tuple Repetition

The combined tuple is repeated three times:

t_repeat = t_combine * 3
Tuple Indexing

The third element is accessed using:

t_combine[2]

Output:

30
Tuple Slicing

First three elements:

t_combine[:3]

Output:

(10, 20, 30)

Last three elements:

t_combine[-3:]

(40, 50, 60)
